
## 第二部分：参赛项目说明

### 1. 核心问题与目标用户

```text
人工导游能根据游客的时间、兴趣和现场进度调整路线、讲解并回应追问，但受人力、服务时段与接待规模限制；传统语音导览多为固定路线和单向播放，通用问答又难以持续理解游客当前在哪里、已经看过什么、剩余多少时间和上一轮在问什么，导致规划、讲解、答疑、引路与离馆服务相互割裂。项目面向博物馆、古建景区与非遗场馆中的自由行游客、亲子家庭、研学群体和文化深度爱好者，提供能够随时使用、因人而变并连续陪伴的数字导游；同时为希望扩展导览供给、提升自助游体验和复用文化内容资产的场馆管理者提供技术支撑。
```

### 2. 核心功能与应用场景

```text
系统覆盖“游前—游中—游后”完整旅程。游前采集语言、可用时间、文化兴趣、讲解深度和角色偏好，从已审核路线与空间关系中生成可行的个性路线和路线开场。游中维护当前位置、已参观点位、剩余行程与时间进度，支持到达、完成、跳过、下一站、空间引路和受控重规划。点位讲解覆盖建筑、工艺与装饰对象，以中性清晰为核心主干，并支持古风书生、儿童友好、专业讲解、静听等多种角色表达。游客可在任意环节询问当前点位、术语、历史、工艺和装饰，进行比较、研学式观察或“再讲详细一点”的连续追问，也可查询开放时间、交通、票务和现场服务等实用信息。系统还提供打卡建议；游览结束后，依据真实参观记录生成总结、专属称号与祝福，并衔接经审核的周边餐饮、奶茶咖啡和休息推荐。适用于文化场馆自助游、亲子讲解、研学参观和文化深度体验。
```

### 3. 技术实现路径

```text
项目以 Python 和 LangGraph 构建状态化 Agent 图，将语义归一、游客画像、路线规划、游览状态、空间引导、问答、讲解和游后总结拆分为可组合、可追踪的流程节点。知识层将场馆基本信息、历史建筑、游览服务、票务规则、建筑装饰工艺和对象整理为带有来源、审核状态和时效字段的结构化知识；采用 BGE 稠密向量检索与 BM25 关键词检索，经 RRF 融合和条件重排生成带来源的受控 RAG 答案。路线层使用审核路线模板、点位目录与空间拓扑，通过 NetworkX 计算合法路径和步行时间，再根据游客时间、兴趣、讲解深度和当前位置进行确定性选路。生成层接入 DeepSeek，先由确定性系统产出路线、问答与讲解事实，再构建结构化 ContentPlan，使模型仅负责角色语气、句式、节奏和组织。候选内容通过 Schema、事实 ID、时长预算、角色一致性与公开输出校验后，才能在限定白名单场景展示；校验未通过时自动回退至中性稳定正文。Coverage 机制记录已讲事实并幂等提交，LangSmith Studio 用于展示节点、候选、校验、回退与状态变化。
```

### 4. 技术创新点与差异化优势

```text
项目的差异不是为通用聊天模型增加几组角色提示词，而是将人工导游的服务逻辑工程化。第一，以跨轮游览状态连接规划、到站讲解、即时问答、空间引路、进度控制和游后服务，形成“一次旅程、持续理解”的陪伴体验，而非每轮重新开始的问答。第二，采用“确定性决策层＋生成式表达层”双引擎：场馆知识、路线、位置与进度先被结构化，模型只决定“怎样讲”，使中性清晰的稳定性与古风书生等角色的沉浸感可以同时存在。第三，以 ContentPlan 和事实 ID 将同一组审核内容转化为儿童、研学、专业、静听、粤语文化等多种表达策略，让角色跨路线、开场、讲解和问答保持连续，又不改变知识边界。第四，Coverage 记录游客真正听过的内容，可减少重复讲解，并为个性总结、称号、祝福和后续推荐提供依据。第五，知识、空间、路线和角色均被建设为可配置数据资产，使陈家祠首个场景跑通后，具备向其他博物馆、古建景区和非遗场馆复用的基础。
```

### 3. 实施路径与预期效果

```text
实施路径分为四个阶段。第一阶段为场景原型固化：已以陈家祠完成可运行原型，将场馆知识、建筑装饰工艺、点位、空间拓扑、审核路线和游览规则建设为结构化资产，跑通画像采集、路线规划、开场引导、到站讲解、连续问答、进度控制、游后总结和周边推荐的完整链路。第二阶段为场馆共创校验：在不改变场馆审核口径的前提下，邀请文博、导览和运营人员对知识、路线、位置表达和角色体验进行专业复核，并通过现场走测优化交互节奏。第三阶段为小范围试点：以H5、小程序或场馆线上服务入口承载系统，先在审核充分的固定路线与重点点位上投入使用，收集游客对路线适配、讲解易懂度、答疑有效性和角色偏好的真实反馈。第四阶段为模板化推广：将陈家祠验证后的知识、空间、路线和角色配置方法沉淀为场馆接入规范，逐步复用到广州其他博物馆、历史建筑、非遗场馆和城市文化游线。

预期效果包括三个层面：对游客，在缺少人工导游陪同时仍能获得符合时间、兴趣和理解方式的个性旅程，并以随时提问、连续追问和角色化讲解提升参与感、理解度与文化记忆；对场馆，扩展可持续服务的数字导览供给，将分散的知识、路线和服务信息转化为可复用、可维护的数字资产，并为高峰客流与自助参观提供补充服务；对广州文旅，形成一套以岭南文化为核心、能够在多类文化场景中复制的AI导游方案，丰富城市智慧旅游服务形态，使文化传播从“统一播放”走向“因人而讲、随程而变、游后有记忆”。
```
